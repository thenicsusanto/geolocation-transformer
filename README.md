# geolocation-transformer

A country-level geolocation classifier that predicts where in the world a Street View image was taken.

Inspired by [PIGEON](https://arxiv.org/pdf/2307.05845) (Haas et al., 2023).

---

## How It Works

Street View images are encoded using a frozen [CLIP ViT-L/14-336](https://openai.com/research/clip) vision encoder. The four directional embeddings are averaged into a single location embedding, which is passed to a linear classifier trained to predict country. Training uses a custom loss that combines standard cross-entropy with a geographic penalty — wrong predictions that are geographically closer to the true country are penalized less.

```
4x Street View Images (N, E, S, W)
        ↓
CLIP ViT-L/14-336 (frozen)
        ↓
Average pool across 4 directions
        ↓
Linear classifier (768 → 104 countries)
        ↓
Country prediction
```

---

## Dataset

~50,000 Street View images across 104 countries, collected via the Google Street View Static API. Sampling locations are generated by:

1. Drawing random points inside each country's geographic boundary using GeoPandas and rejection sampling
2. Snapping each point to the nearest valid Google Street View panorama
3. Downloading 4 images per location (N, E, S, W)

**Stratified sampling** allocates locations per country proportional to a weighted combination of population and area, so large diverse countries (India, Brazil, USA) get more images than small homogeneous ones without completely drowning out smaller countries.

Images are stored as WebDataset shards on AWS S3, with metadata in DynamoDB.

## Training

CLIP embeddings are pre-computed and cached to avoid redundant GPU compute across training runs. Only the linear head is trained.

**Loss function:**

$$\mathcal{L} = \alpha \cdot \mathcal{L}_{geo} + (1 - \alpha) \cdot \mathcal{L}_{CE}$$

Where $\mathcal{L}_{geo}$ is the expected geodesic distance (in km) from the predicted country distribution to the true location, and $\mathcal{L}_{CE}$ is standard cross-entropy. $\alpha$ controls the tradeoff between geographic accuracy and exact country classification.
